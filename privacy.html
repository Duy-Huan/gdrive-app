Privacy Policy

Effective date: November 14, 2026.

Service description

Personal Google Drive Sync is a private-use OAuth configuration used by the owner with the open-source rclone tool. This website is static and does not process Google login responses or receive Drive files.

Information accessed

After the account owner grants consent, rclone accesses Google Drive files and metadata consistent with its selected OAuth scope. This may include file names, directories, metadata, content, and permissions. Where full Drive access is enabled, rclone may modify or delete Drive files at the user's direction.

Purpose

Google Drive access is used only to mount, browse, upload, download, back up, or synchronize the owner's own Drive data through rclone. No Google user data is sold or used for advertising or profiling.

Storage and disclosure

Tokens can be stored locally by rclone, normally within the owner's rclone configuration. File data may be cached locally according to the user's mount settings. Drive content travels between the user's device and Google Drive as needed for authorized operations. This static website has no backend collecting Drive data and the maintainer does not operate a hosted server that collects or shares Drive data.

Security and retention

The owner controls security of local credentials, caches, and downloaded files. Stored credentials and caches remain locally until removed by the owner, while Drive data is retained in their Google account under Google's policies. Never publish rclone configuration files, OAuth tokens, or client secrets. Access can be revoked through Google Account Connections.

Google API data

Google API data is used only to provide the personal Google Drive file access functions described here and not transferred for unrelated purposes.

Contact

Questions may be directed to the maintainer through the GitHub profile.
